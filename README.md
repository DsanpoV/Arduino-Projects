# Arduino Projects

This repository stores my Arduino projects and tracks my learning progress with this technology.

## Projects Index

- [LED Control with Keypad](./LED%20Control%20with%20Keyboard) — Control an 8-LED NeoPixel strip using a 4x4 keypad.  
- [LED Voice Control with Display](./Led%20Voice%20Control%20with%20Display) — Control LEDs and display using simple "yes" and "no" voice commands with Arduino Nano 33 BLE Sense.
- [Smart_Home](./Smart_Home) — Integrated smart home system combining environmental sensing, user behavior modeling, and TinyML-based decision-making for autonomous device control.
- [Sensor_Estacionamento](./Sensor_Estacionamento) - 6 LEDS from red to green that turn up based on the distance an object is from a sensor.

### Notes

Each project folder includes its own `README.md` with detailed instructions, components used, and images of the project setup.
